# AI8051U 灰度感应电子琴

使用 AI8051U 开发板、8 路灰度传感器和 MAX98357A 数字功放制作的八键电子琴。支持多音合成、音色切换、移调、音量调节、内置歌曲播放和 USB 串口调试。

## 当前配置

- 主控工作时钟：40 MHz，使用 Keil C251 工具链。
- 音频：硬件 I2S + DMA，约 16 kHz、16 位双声道，8 个合成声部。
- 输入：8 路数字灰度信号，低电平触发；采用约 5 ms 消抖。
- **灰度模块反装：第 1～8 个逻辑琴键依次对应 P0.7～P0.0。**
- **OLED 显示旋转 180°**，使用 128×64、I2C 接口，当前驱动采用 SSD1306 命令集。
- 两个带按压开关的旋转编码器，另有独立音色切换按键。

## 编译与烧录

1. 安装 Keil µVision 和 **C251/MCS-251** 工具链，并安装 AI8051U 对应器件支持。工程不是普通 C51 或 ARM 工程。
2. 打开 `代码/Piano_AI8051U.uvproj`，选择 `Piano AI8051U` 目标。
3. 执行 Rebuild，固件生成于 `代码/Objects/Piano_AI8051U.hex`。若目录不存在，可先在 `代码` 下新建 `Objects` 和 `Listings`。
4. 用支持 AI8051U 的下载工具烧录 HEX，工作时钟设为 **40 MHz**。
5. 上电后固件先播放两个短测试音，再进入正常使用。

本上传目录未附带预编译 HEX，请由当前源码编译生成。此次整理没有启动 Keil 编译或执行烧录；最新安装方向需在实物上确认。

工程使用相对路径，编译不依赖原电脑的 `D:` 盘目录。不要把 `.map` 或 `.lst` 编译产物长期打开在编辑器中，否则重新编译时可能提示文件变化。个人窗口配置未随仓库提供。

## 操作

| 操作部件 | 功能 |
| --- | --- |
| 8 路灰度传感器 | 触发对应琴键，支持多键合奏 |
| 音调编码器旋转 | 移调，范围 -24～+24 半音 |
| 音调编码器按下 | 在 5 首歌曲间循环选择，并停止当前歌曲 |
| 音量编码器旋转 | 调节音量，默认 200，每步 5 |
| 音量编码器按下 | 歌曲播放、暂停、继续 |
| P2.1 独立按键 | 在 W01～W10 音色间循环切换 |

OLED 显示移调、音色、音量、琴键状态和选歌状态。`>` 为播放，`PA` 为暂停，`STOP` 为停止，`NA` 表示曲目未导入。播放期间音频声部由歌曲使用，暂停或停止后恢复手动琴键。

| 音色编号 | 名称 | 音色编号 | 名称 |
| --- | --- | --- | --- |
| W01 | 钢琴 | W06 | 风琴 |
| W02 | 铃铛 | W07 | 弦乐 |
| W03 | 电钢琴 | W08 | 贝斯 |
| W04 | 木琴 | W09 | 拨弦 |
| W05 | 音乐盒 | W10 | 鼓声 |

这些音色由波表和包络合成，并非乐器录音采样。歌曲包括《静悄悄》《起风了》《九重现实》《五重空洞》《赤伶》。歌曲使用当前音色演奏，不包含原唱人声。

## 工具

正常编译无需安装 Python。仅使用辅助工具时安装依赖：

```sh
python -m pip install -r 代码/tools/requirements.txt
python 代码/tools/usb_tune.py --list
python 代码/tools/usb_tune.py --port COM5 --command "?" --seconds 3
```

`COM5` 替换为实际 USB CDC 串口。完整命令见 [USB 调试说明](docs/USB调试.md)。

`代码/tools/import_midi.py` 用于重新生成 `song_data.h`：

```sh
python 代码/tools/import_midi.py --source ./midi --output 代码/song_data.h
```

工具按固定名称查找 5 个文件：`静悄悄.mid`、`起风了.mid`、`九重现实.mid`、`五重空洞.mid`、`赤伶----HITA.mid`。原始 MIDI 未随目录提供，已有事件数据可直接编译；不要在缺少源文件时运行导入覆盖已有数据。
