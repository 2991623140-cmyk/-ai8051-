# USB 串口调试

完整固件已加入 USB 虚拟串口，使用开发板原有 USB 连接，不增加接线。烧录后重新连接 USB，电脑应出现新的 COM 口；波特率可填 115200。不要选择蓝牙 COM 口。

默认仅在收到命令时输出状态，避免电脑未读取串口时占用演奏主循环。状态包括音量、移调、琴键位图、音频峰值、DMA 完成计数、欠载计数和错误计数。所有命令以回车或换行结束。

| 命令示例 | 功能 |
| --- | --- |
| `?` | 读取状态 |
| `G1`～`G5` | 按曲目编号选歌并停止当前播放 |
| `P` | 歌曲播放/暂停/继续 |
| `R1` / `R0` | 每秒报告一次 / 关闭自动报告（默认关闭） |
| `V200` | 音量设为 200，测试范围 0～32767，如 `V1200` |
| `T-12` | 移调设为 -12，范围 -24～24 |
| `N0` | 按下第 1 个测试音，索引 0～7 |
| `F0` | 松开第 1 个测试音 |
| `C21` | 测试第 1、3、5 个音的和弦；参数是八键位图 0～255 |
| `W0` | 纯正弦持续音，用于比较 |
| `W1` | 泛音波表和衰减包络，默认音色 |
| `W2` | 铃铛合成音色，较长余音 |
| `W3` | 清脆电钢琴合成音色 |
| `W4`～`W10` | 按上述编号切换木琴至鼓声；`W0` 仍可选择正弦测试音 |
| `B7=72` | 第 8 键响度系数设为 72%；键索引 0～7，系数 0～600% |
| `X` | 停止歌曲并松开全部测试音 |

`PEAK` 表示最近一块音频缓冲的数字峰值，不是麦克风测得的响度；`DMA` 会增长并在 65535 后回绕，`UND`、`ERR` 同样是累计的 16 位计数。电脑端读取脚本为 `代码/tools/usb_tune.py`，需要 Python 的 `pyserial` 包。

已修正高速 I/O 时钟默认二分频带来的音频时钟偏低：`HS=1` 时，40 MHz 主控下采样率约 16.0 kHz。`W1` 是带两级泛音的合成音色，并非真实钢琴采样；支持与 `W0` 比较。切换音色后松开并重新触发测试音。

第 1～8 键的默认响度补偿为 80%、80%、80%、80%、42%、35%、34%、31%，已按用户最终试听确认的参数写入固件。默认移调保持 0，默认总音量保持 200，不保存试听期间临时调整的 TR、VOL。混音会预留输出余量，但高音量下功放或喇叭仍可能失真。串口的 `BAL` 显示当前补偿，`B` 命令可微调；串口修改暂存在 RAM 中，断电后恢复固件默认值。
