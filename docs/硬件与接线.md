## 供电与音频

| 信号 | 连接 |
| --- | --- |
| 主控及逻辑模块电源 | 3.3V |
| MAX98357A VIN | 5V |
| 所有 GND | 共地 |
| MAX98357A BCLK | P3.2 |
| MAX98357A DIN | P3.4 |
| MAX98357A LRC / LRCK | P3.5 |
| MAX98357A GAIN | 当前记录为悬空，按现有模块配置 |
| MAX98357A SD | 保持使能，不能接地；按实际模块使能电路接线 |
| 扬声器两端 | SPK+、SPK−，任一端均不接 GND |

开发板的 5V/VIN 和 3V3 不是同一个电源输入。使用 USB 与外部电源同时供电时，应先确认开发板的电源隔离方式。USB 通信及下载连接沿用开发板原电路。

音频使用 I2S 第 0 组：P3.2/P3.4/P3.5。若开发板下载键占用 P3.2，运行时按下会干扰音频。功放电源及喇叭走线尽量短，音频数字线远离功率输出线。

## 灰度传感器：反装映射

传感器输出仍接 P0.0～P0.7。软件将识别顺序反转，**不需要为了反装交换信号线**。

| 逻辑琴键 | 固件索引 | 主控输入 |
| --- | --- | --- |
| 第 1 键 | 0 | P0.7 |
| 第 2 键 | 1 | P0.6 |
| 第 3 键 | 2 | P0.5 |
| 第 4 键 | 3 | P0.4 |
| 第 5 键 | 4 | P0.3 |
| 第 6 键 | 5 | P0.2 |
| 第 7 键 | 6 | P0.1 |
| 第 8 键 | 7 | P0.0 |

琴音、OLED 的 KEY 位图及串口琴键状态都使用逻辑琴键顺序。传感器保持低电平有效，仅顺序倒转；这不是将高低电平反相。模块 DO 电平应匹配 3.3V 主控；检测阈值按实际安装距离和反射面调节。

## 编码器、OLED 与按键

| 元器件信号 | 主控引脚 |
| --- | --- |
| 音调编码器 CLK / A | P1.0 |
| 音调编码器 DT / B | P1.1 |
| 音调编码器 SW | P1.2 |
| 音量编码器 A | P1.3 |
| 音量编码器 B | P1.4 |
| 音量编码器 SW | P1.5 |
| OLED SCL | P2.4 |
| OLED SDA | P2.5 |
| 音色切换键 | P2.1 与 GND 之间 |
| 状态 LED | P3.7，低电平点亮 |
| 闪烁 LED | P2.0，低电平点亮，亮灭各约 0.5 秒 |

编码器若有 VCC/GND，分别接 3.3V/GND。开关按下接地；P2.1 使用内部上拉。外接 LED 接法：`3.3V → 限流电阻 → LED 正极；LED 负极 → 对应 GPIO`。

OLED 采用软件 I2C，SDA 是 **P2.5**，不要改接到硬件 I2C 的默认端口。当前初始化用 `0xA1` 和 `0xC8` 实现 180° 旋转。

## 上电检查

1. 核对电源、共地、开发板插接方向及扬声器端子。
2. 下载器时钟设为 40 MHz，烧录当前源码生成的 HEX。
3. 确认 OLED 方向正确，开机可听到两个短测试音。
4. 逐个触发传感器，确认第 1～8 键与上述反装映射一致。
5. 检查两个编码器旋转及按压、音色按键、选歌播放功能。

此处为代码和已有接线记录的整理；PCB 封装、排针物理位置和实际电气连接仍按实物与 PCB 工程核对。
